## Road Accident Severity Classification (ML + NLP)

This project predicts the **severity of traffic accidents** — classified as **Minor**, **Moderate**, or **Severe** — by combining both **structured** and **textual** data.
It integrates **weather, visibility, location, and time features** with **crash description text** to provide a richer understanding of accident conditions.

The notebook demonstrates a complete **end-to-end machine learning workflow**, including:

* **Data preprocessing** (cleaning, imputation, encoding, scaling)
* **Feature engineering** for both tabular and text inputs (TF-IDF and BERT embeddings)
* **Model fitting and comparison** across Logistic Regression, Random Forest, XGBoost, and Neural Networks
* **Performance evaluation** using Accuracy, F1 score, and computation time
* **Interpretability** analysis via XGBoost feature importances to identify key linguistic drivers of crash severity

This project showcases how **traditional ML methods and NLP techniques** can be combined to improve prediction accuracy and interpretability in real-world transportation data.
